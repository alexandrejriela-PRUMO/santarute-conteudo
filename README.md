# santarute-conteudo

Artes publicadas nas redes da Santa Rute Engenharia Rural e o que a tarefa agendada usa para gerá-las.

- `INSTRUCOES.md`: como os posts são gerados, aprovados e publicados.
- `historico.md`: lista dos posts já publicados.
- `sistema/`: modelo das artes (render.py), logos (vetorizadas) e fontes (Poppins e Playfair Display, licença OFL em `sistema/fontes/OFL.txt`).
- `fotos/`: fotos de campo liberadas para post.
- `posts/`: uma pasta por post (post.json + imagens).

Este repositório é público porque o Instagram precisa buscar as imagens por link aberto.
Não coloque aqui nada que não vá ser publicado.
